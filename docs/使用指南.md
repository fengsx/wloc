# WLOC 使用指南

适用：iPhone 13 mini、iOS 26.5。代码在 [fengsx/wloc](https://github.com/fengsx/wloc)，选点网页在 [wloc.myfeng.workers.dev](https://wloc.myfeng.workers.dev/)。WLOC 改写网络定位响应；最终显示位置还会受 GPS 和系统缓存影响。

## 1. 安装模块

在你使用的代理客户端中，复制对应地址作为模块或覆写订阅，并启用：

| 客户端 | 订阅地址 |
| --- | --- |
| Surge | `https://raw.githubusercontent.com/fengsx/wloc/refs/heads/main/modules/wloc.sgmodule` |
| Quantumult X | `https://raw.githubusercontent.com/fengsx/wloc/refs/heads/main/modules/wloc.conf` |
| Loon | `https://raw.githubusercontent.com/fengsx/wloc/refs/heads/main/modules/wloc.lpx` |
| Stash | `https://raw.githubusercontent.com/fengsx/wloc/refs/heads/main/modules/wloc.stoverride` |
| Shadowrocket | `https://raw.githubusercontent.com/fengsx/wloc/refs/heads/main/modules/wloc.module` |

确认客户端已连接 VPN。若装过其他 WLOC 模块，先停用重复模块。

## 2. 开启 HTTPS 解密

在代理客户端中启用 MITM／HTTPS 解密，按模块配置启用 `gs-loc.apple.com`、`gs-loc-cn.apple.com` 等定位域名。安装**该客户端生成的** CA 证书描述文件，然后在 iPhone“设置 → 通用 → 关于本机 → 证书信任设置”中打开“完全信任”。最后确认 VPN、模块和 MITM 均处于启用状态。

## 3. 选点并保存

1. 确保 Safari 经过已启用 WLOC 的代理客户端，打开 [选点网页](https://wloc.myfeng.workers.dev/)。
2. 在地图上选点，或搜索地点后从候选列表中点选一项。核对页面显示的经纬度，再点击“储存到设备”。
3. 点击当前坐标区域的“刷新”，确认已保存的坐标与选点一致。

首次测试选一个容易核对、经纬度均不为 `0` 的地点。页面显示保存成功，只代表手机上的模块保存了坐标。

## 4. 刷新定位并验证

1. 关闭“设置 → 隐私与安全性 → 定位服务”。
2. 开启飞行模式，确认 Wi-Fi 和蓝牙也已关闭，然后重启 iPhone。
3. 开机后关闭飞行模式，等网络恢复，重新连接代理客户端。
4. 确认 VPN、模块、MITM 都已启用，最后打开定位服务。
5. 完全退出并重新打开 Apple 地图，查看蓝点；也可在客户端日志中检查 `/clls/wloc` 是否被改写。

如果蓝点回到真实位置，可能是 GPS 覆盖了网络定位；可在室内再验证一次。

## 5. 使用快捷指令（可选）

在 iPhone 上点击链接，或用相机扫描二维码，直接加入快捷指令：

| 快捷指令 | 安装链接 | 二维码 |
| --- | --- | --- |
| WLOC设置位置 | [点击安装](https://www.icloud.com/shortcuts/e0d3b9504c1541f182117fe328f68a5b) | ![设置位置二维码](../shortcuts/WLOC设置位置-二维码.png) |
| WLOC恢复定位 | [点击安装](https://www.icloud.com/shortcuts/fddd99ba529b457088243640b28ded6a) | ![恢复定位二维码](../shortcuts/WLOC恢复定位-二维码.png) |

设置位置指令已使用 `wloc.myfeng.workers.dev` 解析地图链接。从 Apple 地图分享一个地点给“WLOC设置位置”，核对通知中的经纬度，再按第 4 节刷新定位。恢复定位可直接运行“WLOC恢复定位”；若想确保立即停用虚拟位置，仍须关闭 WLOC 模块。

## 6. 恢复真实位置

在选点网页点击“清除数据”，**关闭 WLOC 模块**，然后重启 iPhone。若仍显示旧位置，确认没有重复模块或模块内的固定坐标参数。

## 7. 常见问题

| 现象 | 检查 |
| --- | --- |
| 网页打不开或地图空白 | 网络、Cloudflare 地址、地图图层和 `unpkg.com` 资源。 |
| “储存到设备”失败 | Safari 是否经过代理；VPN、MITM、证书完全信任和设置脚本是否生效。 |
| 已保存但位置不变 | 按第 4 节刷新；查看 `/clls/wloc` 日志，并考虑 GPS 或缓存影响。 |
| 显示“无已保存的坐标” | 重新保存并刷新；当前版本会把零度经纬度误判为未保存。 |
| 快捷指令报错 | 检查解析地址、`format=json` 和地图链接变量。 |

当前版本在保存请求缺少经纬度时可能写入 `(0,0)`；请通过网页正常选点，不要手动发送空保存请求。
